This is a straight-line projection (leads = spend ÷ CPL; signings = leads × that month's conversion rate) — it assumes the selected month's cost-per-lead holds at other spend levels. It won't hold forever: May's CPL ($24.70 at ~$1.4K spend) was far cheaper than June/July's (~$65–74 at ~$5.7–7.6K spend), so cost-per-lead has already risen once as spend scaled up. Treat this as a rough directional tool, not a guarantee — actual diminishing returns likely kick in at some point past current spend.
All-time won opportunities (AXISKEY, all pipelines)
"Date Won" is lastStatusChangeAt. "Agreement Signed" defaults to Date Won but is editable (italic = still the default, not yet set) — once changed, it's what the Overview tab uses to classify that deal into a month, ahead of Date Won. "Capital Raiser Intent" and "Agreement Signed" are GHL custom fields on the opportunity record; "Source" is GHL's standard opportunity source field.

GHL's own "Agreement Signed Date" custom field was created 2026-07-23 and was never backfilled on deals won before then — those default to Date Won (shown italic) until you edit it. Deals won since ~7/28 now have a real GHL-set Agreement Signed date (shown plain, not editable-default). Edits are saved in this browser only (not written back to GHL) and immediately reclassify that deal's month on the Overview tab. "Capital Raiser Intent" is populated only where that field was filled in on the opportunity in GHL. "Source" prefers the deal's own source field (kept as-is, including any specific referrer name like "Referral - Diego"); when that's blank it falls back to the contact's "Source" custom field, which is only a coarse category (Referral/Client/SGL/MGL) with no referrer name attached. Remaining blanks reflect missing data on both records, not an extraction issue here.
